## 📖 คู่มือการใช้งาน

### สำหรับผู้รายงานเหตุการณ์

1. **เปิดหน้าเว็บ** - ระบบจะแสดงโหมดผู้รายงานโดยอัตโนมัติ
2. **กรอกข้อมูล** ในฟอร์ม:
   - ชื่อ-นามสกุลผู้รายงาน
   - ตำแหน่ง/หน้าที่
   - วันที่และเวลา (เติมให้อัตโนมัติ)
   - พื้นที่เกิดเหตุ
   - รายละเอียดเหตุการณ์
3. **อัปโหลดรูปภาพ** (ถ้ามี) สูงสุด 5 รูป
4. **คลิกปุ่ม "บันทึกเหตุการณ์"**
5. **ดูรายการ** ที่บันทึกไว้ด้านล่างฟอร์ม
6. **กรองรายการ** ตามสถานะได้ตามต้องการ

### สำหรับผู้ตรวจการ (Admin)

1. **คลิกปุ่ม "โหมดผู้ตรวจการ"** ที่ Header
2. **เข้าสู่ระบบ**:
   - Username: `admin`
   - Password: `admin`
3. **ดูรายงานทั้งหมด** ในรูปแบบตารางหรือการ์ด
4. **คลิกปุ่ม "ตรวจสอบ"** เพื่อ:
   - ดูรายละเอียดเต็ม
   - เพิ่มหมายเหตุผู้ตรวจการ
   - เปลี่ยนสถานะเป็น "ตรวจสอบแล้ว"
5. **บันทึกผลการตรวจสอบ**
6. **ดาวน์โหลด JSON** หรือ **พิมพ์รายงาน** ตามต้องการ

## 💾 การจัดเก็บข้อมูล

ระบบใช้ **LocalStorage** ในการจัดเก็บข้อมูล:

```javascript
// โครงสร้างข้อมูล
{
  id: timestamp,
  reporterName: "ชื่อผู้รายงาน",
  reporterPosition: "ตำแหน่ง",
  date: "YYYY-MM-DD",
  time: "HH:MM",
  area: "พื้นที่เกิดเหตุ",
  detail: "รายละเอียด",
  images: ["base64...", "base64..."],
  status: "pending" | "verified",
  adminNote: "หมายเหตุผู้ตรวจการ",
  createdAt: "ISO DateTime"
}
```

**หมายเหตุ**: ข้อมูลจะถูกเก็บไว้ใน Browser ของผู้ใช้ หากล้างข้อมูล Browser ข้อมูลจะหายไป

```bash

git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin <your-repo-url>
git push -u origin main

# 2. ไปที่ Settings > Pages
# 3. เลือก Branch: main และ folder: / (root)
# 4. คลิก Save
```
